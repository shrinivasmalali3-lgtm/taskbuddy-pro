# 🚀 TaskBuddy Pro + MiniTube Pro

An advanced productivity + video learning dashboard built with React + Vite.

## 🌟 Features

### ✅ TaskBuddy Pro
- Add / Delete / Complete Tasks
- Priority Levels
- Categories
- Dark Mode
- Progress Tracking
- Task Analytics

### 🎥 MiniTube Pro
- Paste YouTube URLs
- Auto Video Add
- Watch Later Playlist
- Real Progress Tracking
- Notes + Bookmarks
- Dashboard Analytics
- Status Filters
- Smart Sorting

## 🛠 Tech Stack
- React.js
- Vite
- JavaScript
- CSS
- LocalStorage
